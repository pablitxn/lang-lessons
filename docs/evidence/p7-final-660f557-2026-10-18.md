No production caller invokes `createCallObservationRepository`. Reproduction: create a canonical call segment, cancel/fail before connection, end the segment, then read recovery history or confirm close. With no trusted observations and no tutor interval, both return `policy-unresolved`; having no remaining broker receipt does not resolve that ambiguity. A genuinely connected call is affected too. The new P7 test isolates this repository decision with an injected DB result; it is not a PostgreSQL end-to-end test. Consequences: attempted-call sessions can become unfinalizable/unrecoverable; connected/listening duration and daily union lack a production input; called-session feedback cannot be demonstrated through the real composition. The fail-closed decision is appropriate, but missing binding is not deferred live acceptance. Never infer connection from SDP creation or browser assertions to fix this.
2. **P2 scoped implementation gap: live transcript/interaction capture is not wired.** `server/index.ts:37` explicitly reports content capture disabled; `server/telemetry.ts:39,81,93` is content-free instrumentation. The synthetic capture contract and feedback metadata path do not capture live tutor transcript/interactions into Phoenix. No persisted audio was introduced in the inspected paths. This remains absent functionality, not a successful feature waiting only for a live smoke test. Retention/deletion policy remains unresolved and must precede enabling content export.
3. **P2 unresolved acceptance/implementation boundary: newly created accounts cannot obtain credentials through the app.** `server/accounts/management.ts:70–77` creates user/role records, no credential, and returns `credentialSetup: 'pending-policy'`. Admin-only creation/access changes exist; own-login onboarding for those accounts is not delivered. Credential delivery/recovery and initial operational provisioning still need an accepted policy. Do not describe the placeholder as usable account creation.

Dictionary source and retention/deletion remain unresolved product decisions. Historical attribution and SQL locking still need independent PostgreSQL verification here.
